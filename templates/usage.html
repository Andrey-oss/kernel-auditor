How to Use Kernel Auditor

Kernel Auditor is designed to help you monitor your system's performance, tweak kernel settings, and optimize your Linux system. Below is a guide to help you get started:

Installation

To install Kernel Auditor, follow these steps:

git clone https://github.com/Andrey-oss/kernel-auditor.git

After cloning the repository, install the necessary dependencies by running:

pip3 install -r requirements.txt
Running Kernel Auditor

Once installed, you can run Kernel Auditor using the following command:

sudo python3 main.py

The tool will open a web interface in your browser where you can monitor your system, tweak kernel parameters, and view hardware stats

Key Features
  • Monitor system info/hardware
  • View system processes
  • Optimize kernel settings for better performance
  • Easy-to-Use interface
Troubleshooting

If you encounter issues, check the following:

  • Ensure all dependencies are installed by checking the requirements.txt file
  • If the web interface doesn't load, try restarting the service or your machine
  • For additional help, visit the GitHub Issues page
  • Also you can write me in Telegram
Contribute
